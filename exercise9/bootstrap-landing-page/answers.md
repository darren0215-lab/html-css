# Bootstrap landing page: my answers

## 1. Which Bootstrap classes did you use for the navbar?

I used navbar, navbar-expand-lg, navbar-brand and navbar-toggler to create the navbar.

## 2. Which value on the navbar button points to the menu?

The data-bs-target="#studioMenu" points to the menu with the matching id="studioMenu".

## 3. Which grid classes changed the layout of the hero section?

I used row and col-lg-6 to arrange the hero section into two columns on larger screens.

## 4. Which card classes did you use?

I used card, card-body, card-title, card-text and h-100 to create the three service cards.

## 5. Which styles did you put in `custom.css`, and not as Bootstrap utility classes in the HTML?

I added my own background colours, text colours, borders, rounded corners and padding in custom.css. I also styled the hero section, service cards, contact section and footer.
