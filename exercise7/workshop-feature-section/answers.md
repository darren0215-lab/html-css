# Image positioning: my answers

## 1. When must an image go in the HTML, with `<img>`?

When I want to show an important picture on the webpage, like the feature photo.

## 2. When must an image go in the CSS, with `background-image`?

When I want to use an image as the background of a section, like the .feature-section.

## 3. What does `object-fit: cover` do?

It makes the image fill the area without stretching it.

## 4. Why does `.photo-panel` need `position: relative`?

.photo-label can stay in the correct position inside the photo panel.

## 5. What makes the text easy to read on top of the background image?

.feature-content has a white background, so the text is easier to read.

## 6. Which change did you make? What changed in the browser, and which CSS property caused it?

background image to the .feature-section. The section now shows a background picture. The background-image property caused this change.
