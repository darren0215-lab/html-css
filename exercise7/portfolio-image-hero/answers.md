# Portfolio image hero: my answers

## 1. Which image goes in the HTML, and why?

The images/portfolio-desk goes in the HTML because it is the main image that shows the user what the page is about.

## 2. Which image goes in the CSS, and why?

The images/portfolio-background goes in the CSS because it is only used as a background to make the website look nicer.

## 3. Which CSS property stops the content image from stretching?

The object-fit: cover property stops the image from stretching. The width and height set the size of the image.

## 4. Which element makes the boundary for the positioned label?

The .image-panel uses position: relative to set the boundary for the label.

## 5. What did you do to keep the text easy to read?

I used font-size: 2.75rem for the main heading and line-height: 1.6 to make the text clearer.
