# CSS foundations: my answers

## 1. Which line in `index.html` connects the CSS file?

`<link rel="stylesheet" href="style.css">`

## 2. In `body { background-color: #ecfdf5; }`, what is the selector?

body

## 3. In that same rule, what is the property and what is the value?

The property is background-color.
The value is #ecfdf5.

## 4. Why does `.resource-card` start with a dot in CSS?

`.resource-card `has a dot, because it looks for a class and The HTML has `class="resource-card"` without the dot, because the attribute value is only the class name.

## 5. What is the difference between padding and margin in the resource card?

Padding makes space inside the element, between the border of the card and the content and margin makes space outside the element, between the card and the things around it.
