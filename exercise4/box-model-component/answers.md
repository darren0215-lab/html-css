# The box model: my answers

## 1. Which element is the parent panel?

The `<div>`with the class ativity-panel.

## 2. Which CSS rule controls the space inside the panel border?

The pandding: 24px; controls the space inside the panel border.

## 3. Which CSS rule controls the space after each panel?

The margin-bottom: 20px; controls the space after each panel.

## 4. Why does the image use `width: 100%`?

Make the image fit the full width of its container.

## 5. Why can both panels use the same CSS?

Because both panels have the same class name,so they can share the same design.
