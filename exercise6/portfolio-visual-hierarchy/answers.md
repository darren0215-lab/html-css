# Portfolio visual hierarchy: my answers

## 1. Which CSS rule makes the strongest text on your page?

The h1 selector makes the strongest text because it uses font-size: 3rem;. This makes the main heading bigger than the other text on the page.

## 2. Which CSS rule makes the paragraph text easier to read?

The line-height property makes the paragraph easier to read because it adds space between each line. This makes the text look less crowded.

## 3. Which color did you use for actions or emphasis?

I used #3c8067, which is a green color for the main button and important text. It stands out from the light background and helps users notice where to click.

## 4. Which spacing choice separates one content group from another?

The gap: 20px; in the .work-list selector creates space between the project cards. It makes the cards look neat and easier to see.

## 5. What becomes more difficult to read quickly if each text element has the same size and color?

It becomes harder to know which information is important. For example, if the heading and paragraph have the same size and color, users may not know where to look first.
