# Typography: my answers

## 1. Which text must the reader see first?

The main heading, which is "Build your first CSS habit."

## 2. Which CSS choice makes that text the strongest?

The font-size: 3rem; makes the heading bigger than the other text. This helps readers notice it easily.

## 3. Which text is supporting information?

"Community Workshop" on line 12 of index.html. It gives readers more information about the website.

## 4. Which color is used for an action or for emphasis?

The orange color #c2410c is used for important text and buttons to make them stand out.

## 5. Which spacing choice separates one content group from another?

The gap property on line 126 of style.css adds space between items and makes the content look more organised.
