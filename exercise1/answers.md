# HTML page structure: my answers

## 1. What is the job of the `head`?

Webpage information

## 2. What is the job of the `body`?

The body contains everything we can see on the webpage.

## 3. Why does `<title>` change the browser tab, and not the visible page?

Because the title is inside the head, so it shows on the browser tab.

## 4. When must you use `<ol>`, and not `<ul>`?

Use <ol> when the list needs to be in order or has steps to follow.

## 5. Why must an image have useful alt text?

Because it describes the image if the image cannot be shown.

## 6. What connects a `<label>` to an `<input>`?

The for attribute connects to the id of the input.
